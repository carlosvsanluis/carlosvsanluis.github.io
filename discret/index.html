Discret: no personal data on a shared screenDiscret : aucune donnée personnelle sur un écran partagé

CRM users share their screen all day: in Teams calls, trainings, demos and bug reports. Discret blurs e-mails, phone numbers, IBANs, card numbers and social security numbers in one keystroke, and copies any value in one click, without revealing it.

Les utilisateurs d'un CRM partagent leur écran toute la journée : réunions Teams, formations, démos, signalements de bugs. Discret floute e-mails, téléphones, IBAN, cartes bancaires et numéros de sécurité sociale d'un raccourci, et copie n'importe quelle valeur en un clic, sans l'afficher.

    What it doesCe que fait l'extension

    Masks personal dataMasque les données personnelles

    Finds e-mails, phone numbers, IBANs (checksum), card numbers (Luhn) and French social security numbers (key check) in fields, grids, notes and free text, plus known Dynamics fields by name. One shortcut blurs them all. Hover tooltips are hidden too.

    Repère e-mails, téléphones, IBAN (clé de contrôle), cartes bancaires (Luhn) et numéros de sécurité sociale (clé) dans les champs, grilles, notes et textes libres, ainsi que les champs Dynamics connus par leur nom. Un raccourci les floute tous. Les infobulles sont masquées aussi.

    Copies in one clickCopie en un clic

    A ⧉ button appears on every field. Alt + click copies any value. It works while masked, so an agent can paste a customer's e-mail into another tool during a call without showing it.

    Un bouton ⧉ apparaît sur chaque champ. Alt + clic copie n'importe quelle valeur. Cela fonctionne même masqué : un agent peut coller l'e-mail d'un client dans un autre outil pendant un appel, sans l'afficher.

    Works beyond DynamicsAu-delà de Dynamics

    Add any web app in the settings. Right-click a field to always mask it on that site. Because it runs in the browser, it needs no deployment in the CRM and no wait for a release.

    Ajoutez n'importe quelle application web dans les réglages. Un clic droit sur un champ le masque toujours sur ce site. Comme tout se passe dans le navigateur, rien à déployer dans le CRM ni de mise en production à attendre.

    How it is builtConstruction

    • Manifest V3 extension for Edge and Chrome, in plain JavaScript with no dependencies.
    • Safe on React apps: it adds data attributes and overlays only, and never rewrites the page structure that Dynamics 365 manages.
    • Least privilege: runs on *.dynamics.com only; other sites need the user's explicit approval, one by one.
    • Tested: unit tests for every detector, including false positives on case numbers, GUIDs, dates and barcodes.
    • Bilingual French / English interface.
    • Extension Manifest V3 pour Edge et Chrome, en JavaScript pur, sans dépendance.
    • Sans risque pour les applications React : elle ajoute seulement des attributs et des calques, sans jamais réécrire la structure de page gérée par Dynamics 365.
    • Moindre privilège : active uniquement sur *.dynamics.com ; tout autre site demande l'accord explicite de l'utilisateur, site par site.
    • Testée : tests unitaires pour chaque détecteur, y compris les faux positifs (numéros d'incident, GUID, dates, codes-barres).
    • Interface bilingue français / anglais.

    Privacy by designConfidentialité dès la conception

    Nothing leaves the browser: no server, no analytics. Copied values stay in session memory and disappear when the browser closes. Saved settings hold field selectors, never values. That matters in insurance, health and any GDPR-sensitive service.

    Rien ne quitte le navigateur : pas de serveur, pas de mesure d'audience. Les valeurs copiées restent en mémoire de session et disparaissent à la fermeture du navigateur. Les réglages enregistrent des sélecteurs de champs, jamais des valeurs. Essentiel en assurance, en santé et dans tout service soumis au RGPD.
